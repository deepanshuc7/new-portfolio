# Deepanshu Portfolio

A personal portfolio website showcasing my work across frontend development, full-stack engineering, UI/UX design, and product thinking.

Live site: [deepanshu.space](https://deepanshu.space)

The site includes selected projects, case studies, education, experience, skills, impact highlights, and contact information.

## Live Sections

- Hero introduction with animated GSAP scribbles
- About section
- Selected impact
- Education and experience
- Categorized skills
- Project showcase
- Detailed case studies
- Contact section

## Case Studies

- **Type Type** - a typing practice app focused on interaction design, state management, feedback loops, and frontend implementation.
- **Mumbai Cafe** - a restaurant website case study focused on visual design, branding, layout, and user experience.

## Tech Stack

- HTML
- CSS
- JavaScript
- GSAP
- ScrollTrigger
- Font Awesome

## Getting Started

Clone the repository and open `index.html` in your browser.

```bash
git clone <repository-url>
cd new-portfolio
```

You can also use a local development server for a smoother preview:

```bash
npx serve .
```

## Notes

This portfolio is intentionally built as a lightweight static website. It focuses on clear storytelling, responsive design, case-study depth, and subtle motion rather than relying on a heavy framework.
